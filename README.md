# XDRPeak

> ⚠️ **Placeholder** — verrà riscritto in M4 (vedi [`PLAN.md`](PLAN.md)) come README "marketing-grade" con badge, demo GIF, screenshot, sezioni con emoji titles e Quick Start.

**XDRPeak** is a macOS menu bar app that unlocks the **peak XDR brightness** of your Apple display — up to **1600 nits** — in any workflow, not just HDR video playback.

Open source under **GPL-3.0**. Based on prior work by [BrightXDR](https://github.com/starkdmi/BrightXDR), [BrightIntosh](https://github.com/niklasr22/BrightIntosh), and [Lunar](https://github.com/alin23/Lunar).
